Spot2Clip
Sua playlist do Spotify virando uma playlist de videoclipes no YouTube.
Cota YT: 0 / 10.000
Trabalho em andamento

1 · Entre com sua conta do YouTube

Abre a janela oficial do Google só para você autorizar. O app nunca vê sua senha. A playlist de clipes será criada no seu canal.

2 · Escolha a playlist

Cole o link da sua playlist do Spotify. Ela precisa estar pública.

Como deixar a playlist pública e pegar o link?

No Spotify, abra a playlist → toque nos três pontinhos (⋯) → Tornar pública. Depois ⋯ → Compartilhar → Copiar link da playlist. Você pode voltar a deixá-la privada depois de usar.

Envie o CSV exportado (ex.: Exportify) ou cole uma lista, uma música por linha, no formato Artista - Música.

3 · Tudo pronto para buscar os clipes

Criar no YouTube

Playlist criada!

Na TV: abra o app do YouTube (logado na mesma conta) → Biblioteca → Playlists. Ou transmita pelo celular.

Configuração inicial (só o dono, uma única vez)

Quem usa o site só cola o link da playlist e entra com o Google. Estes dois dados são do seu app e ficam gravados no código.

Passo a passo

0 · Publique o site (para ter um endereço)

  1. Crie uma conta grátis em github.com → New repository (nome: spot2clip, público).
  2. Clique em uploading an existing file, envie o index.html e salve com Commit changes.
  3. Settings → Pages: em “Branch” escolha main e / (root). Em ~1 minuto o endereço aparece: https://SEUUSUARIO.github.io/spot2clip/. Abra-o e volte a esta janela (…/#setup).

1 · Google/YouTube: Client ID

  1. Entre em console.cloud.google.com e crie um novo projeto (ex.: Spot2Clip).
  2. APIs e serviços → Biblioteca → YouTube Data API v3 → Ativar.
  3. APIs e serviços → Tela de permissão OAuth (ou “Google Auth Platform”): nome do app, seu e-mail, público Externo. Em Usuários de teste, adicione seu e-mail e o de cada amigo (até 100).
  4. Credenciais → Criar credenciais → ID do cliente OAuth → Aplicativo da Web. Em Origens JavaScript autorizadas, cole a “Origem” mostrada abaixo. Crie.
  5. Copie o ID do cliente (termina em .apps.googleusercontent.com) e cole no campo abaixo.

2 · Mini-servidor que lê a playlist (Cloudflare, grátis)

  1. Crie uma conta no plano grátis em dash.cloudflare.com.
  2. Workers & Pages → Create → Create Worker (modelo “Hello World”), nome spot2clip-proxy → Deploy.
  3. Clique em Edit code, apague tudo, cole o conteúdo do arquivo worker.js e clique em Deploy.
  4. Copie o endereço do Worker (termina em .workers.dev) e cole no campo abaixo.
  5. Opcional, recomendado: Settings → Variables and Secrets → crie ALLOWED_ORIGIN com a “Origem” mostrada abaixo, para só o seu site usar o Worker.

3 · Deixar fixo para os amigos

  1. Com os dois campos abaixo preenchidos, clique em Copiar linha para o código.
  2. No GitHub, abra o index.html, clique no lápis (editar), troque a linha const DEFAULTS = … pela linha copiada e faça Commit.
