Guia de instalação

    
Origem do seu site (usada no Google e no Cloudflare): 

    
A · Publicar o site no GitHub Pages
      
    
        
  1. Crie uma conta grátis em github.com → New repository (nome: spot2clip, público).
    2. 
        
  2. uploading an existing file → envie index.html, admin.html, config.js e worker.js → Commit changes.
    3. 
        
  3. Settings → Pages: Branch main, pasta / (root). Em ~1 minuto o site abre em https://SEUUSUARIO.github.io/spot2clip/ e este painel em …/spot2clip/admin.html.
    4. 
      

    
B · Google / YouTube (Client ID)
      
    
        
  1. Em console.cloud.google.com, crie um novo projeto.
    2. 
        
  2. APIs e serviços → Biblioteca → YouTube Data API v3 → Ativar.
    3. 
        
  3. Tela de permissão OAuth (ou “Google Auth Platform”): nome do app, seu e-mail, público Externo. Em Usuários de teste, adicione o e-mail de quem for usar (até 100).
    4. 
        
  4. Credenciais → Criar credenciais → ID do cliente OAuth → Aplicativo da Web. Em Origens JavaScript autorizadas, cole a origem acima. Crie e copie o ID do cliente.
    5. 
      

    
B2 · Liberar o app do Google para qualquer pessoa (sem lista de e-mails)
      
    
        
  1. No Google Cloud, abra Google Auth Platform → Branding e preencha: Nome do app = Spot2Clip; E-mail de suporte; Página inicial = ; Política de Privacidade = .
    2. 
        
  2. Em Domínios autorizados, adicione github.io (se o Google reclamar do domínio, veja a observação no fim deste item).
    3. 
        
  3. Salve. Depois, em Público-alvo → Status de publicação, clique em Publicar app e confirme.
    4. 
        
  4. Quem entrar verá o aviso “O Google não verificou este app”: Avançado → Acessar Spot2Clip (não seguro). O limite sem verificação é de 100 usuários novos no total.
    5. 
      

    
C · Cloudflare Worker (lê a playlist e conta o limite do YouTube)
      
    
        
  1. Crie uma conta no plano grátis em dash.cloudflare.com.
    2. 
        
  2. No menu da esquerda: Compute → Workers & Pages → Create (ou, na página inicial, Create app) e escolha começar com Hello World. Nome: spot2clip-proxy → Deploy.
    3. 
        
  3. Edit code → apague tudo → cole o conteúdo de worker.js → Deploy.
    4. 
        
  4. Copie o endereço ….workers.dev para o campo acima.
    5. 
        
  5. Recomendado: Settings → Variables and Secrets → crie ALLOWED_ORIGIN com a origem acima, para só o seu site usar o Worker.
    6. 
        
  6. Contador compartilhado do limite do YouTube (recomendado): em Storage & databases → KV → Create, crie um namespace chamado spot2clip-quota. Depois, no Worker, abra Settings → Bindings → Add → KV namespace, use o nome de variável QUOTA, escolha o namespace criado e faça Deploy. Sem isso, o site usa só uma estimativa de cada navegador.
    7. 
        
  7. Chave do administrador (para o botão “Sincronizar”): em Settings → Variables and secrets → Add variable, use o nome ADMIN_KEY, um valor longo e secreto (marque Secret) e clique em Add variable and deploy. Anote esse valor: é o que você digita no campo “Chave ADMIN_KEY”.
    8.
